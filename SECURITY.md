# Security

BlitzClean can inspect local processes and permanently delete explicitly selected files.
Process-control bypasses, unsafe path handling and disclosure of local credentials are security issues.

Please use GitHub's **Report a vulnerability** feature if it is enabled on the repository.
If it is unavailable, open an issue asking for a private contact without including exploit details,
secrets, private paths or conversation contents. Do not attach raw command lines or memory-history files publicly.

The project is an early release and has no formal response-time commitment.
